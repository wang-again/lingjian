      三分钟上手第一次用，只走这五步

      1. 1
        连上你的模型

        点侧栏「模型配置」，填 API 地址、密钥和模型 ID；先点「测试连接」，通过后保存。暂时没有 API 也能用——编辑、导入、导出、结构检查都不受影响。

      2. 2
        新建，或把现有文件带进来

        左上角「新建文档」从空白开始。手上已有 Word、PDF、Excel、PPT 或文本，就用「最近文档」右上角的上传按钮导入，文字和标题会一并带过来。

      3. 3
        先说清这份文档要干什么

        打开顶部「文档操作」中的「文档简报」，至少填「写作目的」和「目标读者」两栏。简报只是要求，不会被当成事实。

      4. 4
        让助手起草，或自己写

        打开「写作工具」，输入要求，按 Ctrl + Enter。可以选择撰写全文、生成大纲、接着续写或审阅全文。只想修改一段时，先选中正文，再右键选择「AI 修改选区」。内容会实时写进正文，不满意随时「撤回 AI 修改」。

      5. 5
        交出去之前点一次「交付检查」

        它会一次跑完结构、占位符、引用和依据覆盖，给你三档结论：可以交付、建议再确认、有必须处理的问题。把「必须处理」清完，再导出。

      只记一句话：简报在写之前，体检在交之前。中间怎么写都行。

      五个常见任务照着做，不用理解原理

      从零写一份报告或方案

      1. 「新建文档」，把标题改成正式名称。
      2. 「文档简报」里写清目的、读者、范围。
      3. 打开「写作工具」，填写主题、篇幅、必须包含哪几节。
      4. 生成后逐段改，标题层级用工具栏的「段落样式」。
      5. 「交付检查」清完问题，再「导出文档」。

      一堆资料，要变成一份文档

      1. 「写作工具」→「参考资料」→ 添加文件，Word、PDF、Excel 都行。
      2. 勾选这次要用的资料；没勾的不会发出去。
      3. 简报里补「关键事实」和「术语与口径」，防止模型自己编。
      4. 让助手起草，引用处会自动带上 [资料：文件名]。
      5. 点「核对依据」逐条核对，再「交付检查」看覆盖率。

      改一份已有的 Word

      1. 左侧「文件处理」→ 上传那份文件。
      2. 右侧写清改什么，例如「第三节拆成两节，补一段风险说明」。
      3. 直接「开始处理」生成新文件；想先看改动就点「生成修改建议」逐条确认。
      4. 结果在左侧文件库，下载即可；原文件不会被覆盖。

      交稿前自己查一遍

      1. 点「交付检查」，等结果出来。
      2. 先看结论，再按「必须处理 → 建议确认 → 提示」从上往下清。
      3. 「必须处理」没清完，别急着导出。
      4. 改完正文再点「重新检查」，旧结果会标成过期。

      几篇文档一起管

      1. 「章节工作台」里能看每章字数、空章节和引用数。
      2. 空章节可一次排进队列，让模型逐章补；队列串行，不会互相覆盖。
      3. 「项目资料」建一个项目共用资料，绑定的文档都能用。
      4. 「批量审计」勾几篇一起跑，得到对比表和共有问题。
      5. 常用的排法存成「任务配方」，下次一键重放。

      想统一成单位常用的框架

      1. 找两三份写得好的同类文档。
      2. 「模板中心」→「从范文提炼模板」，勾选这几份。
      3. 确认抽出的章节和表格列，命名保存。
      4. 以后新建文档在「我的模板」里选它。

      按钮速查

      文档简报、核对依据、交付检查、章节工作台和历史版本均在顶部「文档操作」中。

      按钮什么时候点点完会发生什么
      文档简报动笔之前打开七栏表单：目的、读者、范围、关键事实、术语、交付约束、资料政策。保存后每次写作都会带上，文档里也会显示完成度。
      核对依据正文写完之后抽出正文里可核查的句子，逐条和勾选的资料比对，标出有依据、依据偏弱、没有引用、引用失效；点条目能跳回正文那一句。
      交付检查交稿前一次跑完结构、占位符、引用与依据覆盖，给出三档结论和百分制得分，按「必须处理／建议确认／提示」分组。
      章节工作台长文档、要分章推进面板里四个页签：章节与队列、项目资料、批量审计、任务配方。
      历史版本改坏了、想回头查看并恢复之前的版本。每次保存都会留一版。
      导出导出文档时Word（保留标题、列表、表格和图片）、Markdown、纯文本，或打印存成 PDF。
      模板中心不知道从哪下笔挑一个内容框架套用；也可以从自己的范文提炼私有模板。
      文件处理要动 Word／Excel／PPT／PDF上传后描述要做什么，结果另存副本，可下载。原文件不动。
      模型配置第一次用、想换模型填地址、密钥、模型 ID，可测试连接。密钥默认只在本次运行内有效，重启后重新填写。
      备份全部文档迁移或备份时，在侧栏展开「备份与恢复」导出一个 JSON 文件；新环境用「导入文档备份」还原。

      三条习惯能让结果好一大截

      1. 1
        动笔前说清三件事

        这份文档给谁看、要他做什么决定、只允许用哪些材料。这三句话写进简报，等于把返工挡在门外。

      2. 2
        数字和结论后面挂来源

        写到关键数据时，顺手标上 [资料：文件名]。「核对依据」才能替你核对，否则只能提示「无资料可核」。

      3. 3
        交前看「必须处理」，别盯分数

        分数只反映检查项的严重程度。真正要看的是那几条必须处理的：占位符没补齐、引用指向不存在的资料、章节是空的。

      常见问题按遇到频率排的

      没有 API 密钥，能用吗？

      能。写、改、导入、导出、简报、结构检查、模板都能用。只有 AI 起草和文件处理需要模型。

      AI 直接把正文改了，改坏了怎么办？

      顶部的「撤回 AI 修改」可以整轮撤回，也可以从「文档操作」打开「历史版本」。修改正文期间可以停止任务。

      为什么有些句子显示「无资料可核」？

      说明这句话没引用资料，或者引用没指向具体原文。补一条 [资料：文件名] 引用、或补一份资料，再点「重新检查」。

      结论显示「建议再确认」是什么意思？

      没有阻断问题，但有几处要人看一眼，比如占位符残留、标题层级跳跃、依据覆盖率偏低。照着列表清掉就会变成可交付。

      为什么检查结果变灰，还写着「过期」？

      这次检查之后正文又改过。结果只对当时那一版有效，重新点一次检查就行。

      导入 Word 后格式变了吗？

      导入只取文字、标题、列表和表格，分栏、页眉页脚、文本框不会保留。要保留原版式，请用「文件处理」直接改原件。

      导出能带图片吗？

      Word 和 PDF 导出可保留图片。Markdown 和纯文本导出适合提取文字。

      文档存在哪儿？会被上传吗？

      存在这台电脑上。只有你主动执行 AI 任务时，当前正文、写作要求和勾选的资料才会发给你自己配置的服务商。

      换电脑怎么带走？

      侧栏底部「备份全部文档」导出 JSON，新环境点「导入文档备份」还原。建议每周做一次。

      提炼出来的模板在哪儿？

      模板中心 →「我的模板」。最多 30 份，可以删除；删掉后用过它的文档会解除关联，正文不受影响。

      它不做什么这几件事仍要你自己判断

      把边界写清楚，比把功能说满更有用。

      • 1
        不判断外部事实真假

        依据台账只回答一个问题：你给的资料是否支持这句话。它不联网求证，也不替你做事实核查。

      • 2
        不核对图片、公式和页面版式

        导出后的 Word 排版、图注、表格跨页仍需人工看一遍。

      • 3
        不代替终审

        分数不是内容质量评分，只是已执行检查项的严重程度。最终签字的人还是你。
