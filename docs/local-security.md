# 账号模式与本地数据安全

本项目当前面向本机运行：服务默认只监听 `127.0.0.1:3210`，不提供服务器部署方案。默认是无需登录的单机模式；本文说明开启账号模式后的数据目录、管理员设置、密钥存储与调用限制。

## 两种模式

`npm start` 默认启用单机模式：不登录，打开页面就是工作区，数据直接在 `.data/` 下，适合一个人在自己电脑上使用。同一台电脑上任何能打开这个页面的人都能看到同一份文档。

需要把一台电脑分给多人使用、各看各的文档时，在 `.env` 设置 `LINGJIAN_AUTH_MODE=accounts` 并重启，登录页就会出现。此时文档、文件库和模型配置按账号隔离，用户名支持 3–40 位文字、数字、下划线和短横线，密码为 12–128 个字符。系统没有管理员共享模型密钥，每个用户自行填写自己的密钥。

| 能力 | 单机模式（默认） | 账号模式 |
| --- | --- | --- |
| 登录 | 不需要 | 需要，Cookie 会话 |
| 数据位置 | `.data/workspace.json` | `.data/users/<用户ID>/workspace.json` |
| 记住密钥 | 不支持 | 配置主密钥后可勾选 |
| 管理端 | 不开放 | 仅管理员可见 |
| 限流 | 无 | 每账号每分钟与并发限制 |

## 本机验证与旧数据

账号模式下在登录页注册两个账号，即可验证各自的文档、文件库和模型配置。

旧版数据保持原样，新账号不会自动获得旧文档。先注册自己的账号，然后停止服务：

```powershell
node tools/migrate-workspace.mjs --username 你的用户名
node tools/migrate-workspace.mjs --username 你的用户名 --apply
```

第一条只预览数量；第二条复制旧文档、非敏感模型配置和文件库。相同 ID/路径但内容不同会拒绝覆盖。迁移中断后可以重试；原数据不删除，也不迁移旧的内存密钥。需要回到单机版本时，将 `.env` 中 `LINGJIAN_AUTH_MODE` 改为 `local` 并重启，即可继续访问原工作区。迁移后对账号工作区的修改不会反向同步到旧工作区。

## 管理端与管理员设置

账号模式提供「管理端」导航，仅管理员可见。可搜索、分页查看用户、角色、启停状态、在线会话、执行中任务、文档和模型配置数量，以及文件库文件数和占用。统计不返回正文、文件名或模型密钥，文件库占用不包含备份和临时目录；最多扫描每账号 10000 个目录条目，超出或读取失败时标注不完整。没有 Token 费用统计、磁盘配额或在线注册开关，注册仍由环境配置控制。单机模式不开放管理端接口。

同一数据目录只允许一个进程运行。正常停止会释放 `.data/.service.lock`。若进程异常退出，请先查看锁文件的 PID 并确认旧服务已结束，再删除该锁文件；不要在服务运行时删除。迁移和备份均在停止服务后执行。

## 管理端与管理员设置

账号模式提供「管理端」导航，仅管理员可见。可搜索、分页查看用户、角色、启停状态、在线会话、执行中任务、文档和模型配置数量，以及文件库文件数和占用。统计不返回正文、文件名或模型密钥，文件库占用不包含备份和临时目录；最多扫描每账号 10000 个目录条目，超出或读取失败时标注不完整。没有 Token 费用统计、磁盘配额或在线注册开关，注册仍由环境配置控制。

所有新注册及旧版未指定角色的账号都为普通用户，不会自动认领管理员。请先注册自己的账号，再停止服务，在项目目录执行：

```bash
node tools/manage-admin.mjs --username 你的用户名
node tools/manage-admin.mjs --username 你的用户名 --apply
```

第一条只预览，第二条实际授予管理员；工具通过数据锁阻止与运行中的服务同时写入。重启服务并重新登录后出现管理端。此流程不创建默认管理员、不设置默认密码。授予其他管理员使用相同命令；撤销时增加 `--revoke --apply`，不能撤销最后一个启用的管理员。角色修改仅通过命令行进行，注册请求不能自行指定角色。

停用账号立即撤销其所有会话、临时密钥并中止会话绑定任务，文档和文件保留；启用后须重新登录。执行中的已落盘文件操作不会被回滚。页面禁止停用当前管理员，管理接口实时核验角色、会话与 CSRF，不以导航隐藏作为权限控制。账号角色和停用状态保存在 `accounts.json`，旧数据兼容读取。

启停与角色变更在同一次账号数据写入中记录操作人、目标、时间和动作；每账号保留最近 20 条管理记录，页面展示全站最近 30 条。它是操作记录，不是不可篡改的审计存档。备份与迁移时保留 `accounts.json`，避免丢失角色与停用状态。

## 密钥存储

账号模式下密钥默认只在登录会话的服务端内存保存，退出、空闲 30 分钟、登录超过 8 小时或重启服务后清除。Cookie 只包含随机会话标识，没有 API Key。账号每次登录获得独立 CSRF 令牌，每个账号最多同时保留 5 个登录会话。

单机模式下密钥同样只在服务端内存中保存，但因为没有会话概念，它只在本次进程生命周期内有效：重启服务后需要重新填写。单机模式不提供「记住密钥」。

如需开启「记住密钥」，在本机终端生成一次随机主密钥：

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```

将生成值设置为 `LINGJIAN_KEY_ENCRYPTION_KEY` 后重启。可以使用本机环境的私密变量或限制读取权限的 `.env`；仓库已忽略 `.env`。Linux 建议 `.env` 权限 600、数据目录 700、运行账号 UMask=0077；Windows 将项目数据与配置的 NTFS 读取权限限制到当前用户。

用户主动勾选后，密钥使用 AES-256-GCM 加密，绑定用户、模型配置和 API 来源，密文位于对应用户的 `keys.json`。密钥不会在 bootstrap、模型配置响应或文档备份中返回。修改 API 来源需要重新提供密钥；单击「清除此配置的密钥」会清除服务端密文及该账号所有登录会话的对应密钥。更换或丢失主密钥后，已保存密钥需重新填写。

应用代理调用模型必须在执行时解密；本机其他用户或能控制该进程的程序仍可能接触密钥。加密主要保护数据文件单独泄露的情形，不能保证主机失陷后密钥安全。主密钥应与 `.data` 备份分开保管。工具子进程不继承名称含 KEY、SECRET、TOKEN、PASSWORD、CREDENTIAL 或 INVITE 的环境变量。

## 调用范围与限制

默认允许五家预设模型域名、OpenAI 及百炼国际站。自定义中转或百炼业务空间域名需加入 `MODEL_ALLOWED_HOSTS`，例如 `api.example.com,workspace.example.aliyuncs.com`；不支持通配符。模型网络请求禁止自动跟随重定向。本地模型可直接使用无密钥的 localhost 地址。

登录/注册每来源、每用户名在 15 分钟内最多尝试 15 次；每账号 API 最多 300 次/分钟，模型测试、模型列表、写作及 Office 任务/上传合计最多 30 次/分钟。同账号最多 2 个重任务并发，实例最多 16 个；限流返回 429。计数在重启后重置。文档和模型配置上限按账号计算，单文件上传最多 20 MB。

单机模式不设登录与账号级限流（没有可区分的账号），实例级并发上限与各项文件、字符上限仍然生效。这也意味着单机模式没有防爆破的登录限制——它本来就没有登录。

当前尚无按账号的磁盘总配额和费用统计（单机模式只有一份工作区，也没有账号可统计）。上传文档的解析库不构成操作系统级沙箱；本机运行仍需注意只导入自己信任的文件。

## 验证

```powershell
npm run check
npm test
```

`tests/accounts.test.mjs` 使用临时目录和模拟模型，验证身份鉴权、跨账号文档/文件/密钥隔离、CSRF、会话注销/过期、加密跨重启、清除密钥、邀请码和限流、公共来源/Cookie/模型域名限制、并发取消及可重试迁移。不会读取真实账号或使用真实模型密钥。
