# 资料归纳

先明确要回答的问题，再按资料逐份读取。文件智能体须实际调用对应读取工具；仅看到文件名不能算读过资料。普通写作使用随请求提供的正文与已启用资料。

按“事实或数据—来源—可定位位置”整理依据。能确认页码、工作表、章节或段落编号时一起注明；工具未提供位置时只标文件名，不推测页码。不要把不同时间、统计口径或主体的数据合并成同一事实。

文件资料较长或问题聚焦时，可先调用 search_sources，files 必须使用本次选中文件 ID，query 填关键词或短语（空格分隔表示任一词匹配）。结果包含原文 excerpt、真实 location 和可直接引用的 citation。需要更多上下文时再调用读取工具。检索结果只代表匹配片段，不代表全文审阅；交付时说明覆盖范围，并保留工具返回的截断、无法读取或无文字层提示。未命中不能推断事实不存在。

输出适合任务的摘要、证据清单、冲突项与待补充信息。资料之间有分歧时并列说明，不自行选择一个数字冒充已核实结果。输入被截断时说明覆盖范围，按工具支持的模式分次读取；扫描件没有可提取正文时说明需要 OCR。

仅在用户要求输出文件时生成文件。生成 Word 使用 write_docx，遵循其 content_json 契约；交付前由 check_docx 检查。普通写作只返回草稿，等待用户应用。
