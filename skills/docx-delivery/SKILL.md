# DOCX 交付检查

对每个选中的 Word 文件调用 check_docx。用户明确提出必要章节时，通过 required_sections 传入实际章节名称；未提出时做通用检查，不自行添加验收要求。

检查结果的 failed 表示文件结构或正文存在阻断问题；needs_review 表示缺章、占位符或其他需确认的问题；passed 只表示已执行的结构检查通过。读取 JSON 检查报告中真实的 findings 和 limitations，逐项说明文件名、位置、问题和建议动作。

此技能用于检查，默认不修改文件。需要查看上下文时可调用 read_docx；后续修复须按用户要求另存副本，并重新检查新文件。

交付报告应包含检查状态和可下载报告路径。visual_review 为 false 时必须说明未完成页面排版目检，不能声称分页、字体、溢出或事实正确性已经验证。
